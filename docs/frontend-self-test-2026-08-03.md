## 本轮修复

1. 修复新任务提交后，“我的任务”仍停留在旧任务的问题。
2. 修复开发服务器把不存在的 3D Tiles 地址误判为有效资源的问题。
3. 增加 Cesium 1.95 与新版地形、3D Tiles 加载方式的兼容处理。
4. 增加格网 API 离线时的本地模拟格网，并降低默认透明度、缩小格网厚度，避免遮挡校园模型。
5. 修复全局快捷键卸载时机错误导致的 Vue 生命周期警告和重复监听风险。

- 自测过程只使用浏览器本地模拟数据，不会写入真实数据库。

- 构建过程中存在 Cesium 依赖的浏览器兼容提示，但不影响构建结果与本轮页面功能。
