# 二维定高航线转弯代价设计

## 背景与范围

当前动态航线规划器在二维网格上执行定高 A* 搜索。所有搜索节点共享同一飞行高度，因此本阶段的 `C_maneuver` 只计算转弯代价。爬升和下降不参与选路，相关统计值明确记录为 0，避免产生不存在的垂直机动代价。

本设计不扩展三维高度层，不改变建筑、允许飞行高度和临时禁飞区等硬约束，也不修改静态风险、人流风险或航程距离的定义。

## 目标

- 转弯代价必须在搜索过程中参与累计成本，而不是在路线生成后补算。
- 风险和航程相近时，较高的转弯权重应使算法偏向转弯更少的路线。
- 输出能够解释转弯次数、累计转弯角度、原始机动代价和加权机动贡献。
- 保存及重规划流程能够复用实际生效的机动权重。
- 现有调用方在不传新参数时继续工作。

## 方案选择

采用方向感知 A*。搜索状态由“当前网格节点”扩展为“当前网格节点 + 进入方向”。二维八邻域对应 8 个进入方向，起点使用单独的无方向状态。

不采用路线生成后补算，因为后处理代价无法影响 A* 的路径选择。不采用三维 A*，因为当前阶段没有可供搜索的高度层，并且用户已确认仅实现二维定高条件下的转弯代价。

## 成本模型

### 单次转弯

相邻移动方向相同时，转弯角度为 0，不产生代价。方向改变时，使用八邻域方向之间的最小夹角，取值范围为 45°、90°、135°或180°。

单次原始转弯代价按等效航程米数计算：

```text
turn_cost_raw = 10 × turn_angle_degrees / 45
```

因此，45°、90°、135°和180°分别折算为 10、20、30和40米等效代价。默认每45°折算10米。

### 路径机动代价

```text
C_maneuver = Σ(turn_cost_raw)
C_maneuver_weighted = maneuverWeight × C_maneuver
```

`maneuverWeight` 对应总公式中的 δ，默认值为 1，必须为非负有限数。调用方可以通过 `dynamicCostOptions.weights.maneuver` 配置该值。

### 总成本

每次状态转移的搜索成本为：

```text
edge_cost = distance_meters × (distanceWeight + riskScale × Σ(normalized_risk × risk_weight))
            + maneuverWeight × turn_cost_raw
```

整条路径的成本满足：

```text
total_cost = distance_cost + risk_cost + maneuver_cost
```

A* 启发函数仍只使用到终点的直线距离乘以最小通行单价，不估计未来转弯代价。由于转弯代价非负，该启发函数保持可采纳性。

## 搜索状态与路径重建

- 状态键包含网格节点编号和进入方向。
- 起点状态没有进入方向，第一次移动不收取转弯代价。
- 同一网格从不同方向进入时视为不同状态，因为其后续最优转弯成本可能不同。
- `gScore`、`fScore`、关闭集合和前驱关系均按状态存储。
- 到达任一终点方向状态后，从状态前驱链重建网格节点路径。
- 静态兜底规划继续使用机动权重 0，保持原有行为；动态 Cost 规划启用模型中的机动权重。

## 配置、持久化与重规划

动态 Cost 模型新增：

```text
maneuverWeight: 1
```

三个现有 Cost 档位的默认值均为 1。有效权重以 `cost_weights.maneuver` 保存到规划上下文。重规划、安全返航等既有流程继续把保存的 `cost_weights` 传回动态 Cost 模型，因此会复用同一机动权重。

固定的每45°等效10米属于当前模型版本的计算规则，不作为用户输入保存。

## 决策记录与界面

路径成本明细新增独立的 `maneuver` 对象，至少包含：

- `turn_count`
- `total_turn_angle_degrees`
- `turn_equivalent_meters`
- `weight`
- `cost_contribution`
- `climb_meters: 0`
- `descent_meters: 0`
- `climb_cost: 0`
- `descent_cost: 0`

同时增加顶层 `maneuver_cost`，并在决策模型中记录 `maneuver_weight`。路线选择依据页面新增“机动 Cost”指标，并展示转弯次数和累计转弯角度。风险 Cost 仍只包含静态、人流、天气、实时事件和能耗，不得把机动 Cost 混入风险 Cost。

## 边界情况

- 路径不足三个节点时，转弯次数和机动代价均为 0。
- 连续同方向移动不计转弯。
- `maneuverWeight` 为 0 时，搜索结果应退化为不考虑转弯的现有行为。
- 非法、负数或非有限权重采用现有数值归一规则，最终值不得小于 0。
- 路径简化只影响展示点；成本与转弯统计以 A* 原始节点路径为准，确保搜索成本和解释结果一致。

## 测试与验收

采用测试驱动实现，先增加会因功能缺失而失败的真实行为测试，再编写生产代码。

至少覆盖：

1. 默认模型返回 `maneuverWeight = 1`，自定义 `weights.maneuver` 能生效。
2. 直线路径的转弯次数、累计角度和机动 Cost 均为 0。
3. 已知折线路径的转弯次数、累计角度及加权贡献符合公式。
4. 在风险相同的两条候选通道中，机动权重为 0 时选择更短但转弯更多的路线；提高机动权重后选择更平滑的路线。
5. `total_cost = distance_cost + risk_cost + maneuver_cost`，三项不重复计权。
6. 任务保存后 `planning_context.cost_weights.maneuver` 等于实际生效权重。
7. 动态路线、任务审批、重规划、安全动作、路线解释和前端构建回归通过。

## 暂不实现

- 三维高度层搜索。
- 起飞和降落阶段建模。
- 爬升率、下降率、最小转弯半径及具体机型动力学。
- 根据载重、速度或无人机型号动态调整每45°等效米数。

这些能力需要额外的飞行器参数和三维状态空间，应在后续独立设计中实现。
